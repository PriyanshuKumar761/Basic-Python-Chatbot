# Basic Python Chatbot 🤖

This is a simple rule-based chatbot created using Python.

## Features

* Answers basic questions
* Uses a dictionary for responses
* Uses functions and loops
* Takes user input
* `bye` command exits the chatbot

## Technology Used

* Python

## How to Run

Run the following command in the terminal:

```bash
python chatbot.py
```

## Example

```text
Please ask your question: hello
Hi, welcome. how can i help you?

Please ask your question: who are you
i am smart AI chatbot

Please ask your question: bye
Goodbye!
```
